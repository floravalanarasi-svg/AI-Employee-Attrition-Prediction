# AI-Employee-Attrition-Prediction

AI-Based Employee Attrition Prediction Using Machine Learning Algorithms and Explainable AI.

## 1. Project Overview

Employee attrition refers to employees leaving an organization. This project uses Machine Learning algorithms to predict whether an employee is likely to leave the company.

The project also uses Explainable AI techniques to understand the factors influencing employee attrition and help organizations make better decisions.

## 2. Project Objectives

- Predict employee attrition using Machine Learning.
- Analyze important factors influencing employee turnover.
- Compare the performance of different ML algorithms.
- Use Explainable AI to interpret model predictions.

## 3. Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Explainable AI

## 4. Project Files

- `profinal.ipynb`
- `Employee_Attrition_Prediction.ipynb`

## 5. Applications

- Employee retention analysis
- Human Resource management
- Workforce planning
- Employee performance analysis

## 6. Conclusion

This project demonstrates how Machine Learning and Explainable AI can support employee attrition prediction and help organizations understand the factors associated with employee turnover.
